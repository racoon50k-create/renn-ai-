Hubungkan Renn AI

Masukkan URL backend Renn AI yang sudah kamu deploy, misalnya alamat server yang menyediakan POST /chat. Jangan masukkan API key rahasia ke website ini.

Backend harus menerima JSON {"messages":[{"role":"user","content":"Hai"}],"image_data_url":null} dan mengembalikan {"reply":"..."}. Untuk hosting website statis saja, chat demo tetap bisa dipakai tanpa koneksi AI.
